# OSC 7501 — Program Status Protocol (Sill consumer contract)

License: MIT. This document describes how Sill parses and consumes the public
OSC 7501 program-status sequence published by M. Hashimoto (2026-10-06).
It is the **primary** source of per-pane program state in Sill; hook adapters
(`sill state`) only feed the same five-point model when a CLI cannot emit 7501 yet.

## Wire format

```text
ESC ] 7501 ; key=value:key=value ... ST
```

- `ST` is `ESC \` (`0x1b 0x5c`) or `BEL` (`0x07`).
- Pairs are separated by `:` inside the parameter payload.
- `state` is **required**. A 7501 sequence without `state` is dropped entirely.
- Unknown keys are ignored. Unknown OSC code points are ignored. Neither may
  corrupt the byte stream or the pane.

## Keys

| Key     | Rule                                                              |
|---------|-------------------------------------------------------------------|
| `state` | Required. One of `idle` `working` `done` `blocked` `error` `clear` |
| `app`   | Optional. Stable program name, e.g. `claude-code`.                 |
| `msg`   | Optional. One line of base64. Bad base64 → drop `msg`, keep `state`.|
| `kind`  | With `state=blocked`: `permission` `question` `auth`.              |
| `id`    | Optional. Layers records; `state=clear` deletes records by `id`.   |

## Rail mapping (V1)

| 7501 `state` | Rail badge              | Focus ring |
|--------------|-------------------------|------------|
| `working`    | processing              | no         |
| `blocked`    | awaiting; subline `kind`| yes        |
| `done`       | done-unread dot         | no         |
| `idle`       | idle                    | no         |
| `error`      | error                   | no         |
| `clear`      | clears record(s) by `id`| no         |

No 7501 and no hook → rail shows `unknown` plus process liveness. Never guess.

## Examples

```text
ESC ] 7501 ; state=working:app=claude-code ST
ESC ] 7501 ; state=blocked:kind=permission:app=claude-code ST
ESC ] 7501 ; state=done:app=claude-code ST
ESC ] 7501 ; state=clear:id=1 ST
```

## `sill state` fallback write-path

Adapters translate an official CLI hook into the same model and write it via:

```text
sill state agent=claude status=awaiting pid=41220 session=sess_01 [kind=permission] [msg=...]
```

Rules: events without `pid` are dropped (FR-008). The app consumes these records
exactly like 7501 `blocked/awaiting` state. `sill state` is not the primary protocol.
